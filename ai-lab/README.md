# AI Lab

Developer utilities for Haki Shield filter data.

- `langs/python/analyze_easylist.py` counts EasyList line types and extracts safe `||domain^` hosts.
- `langs/cpp/scan_rules.cpp` cross-checks those counts with a stream scanner.
- `langs/ts/verify-rules.ts` validates rule IDs, limits, resource types and protected-site exclusions.

See `langs/README.md` for commands.
