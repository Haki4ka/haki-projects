# Haki projects

Three small, self-contained browser projects.

| Folder | What it is |
|---|---|
| `haki-shield/` | Manifest V3 ad blocker for Chromium and Brave: network rules, a universal EasyList-derived layer, video-ad protection and Twitch stream hooks. |
| `haki-oled-switcher/` | One toolbar button for a pure-black Brave theme and independent site darkening. |
| `ai-lab/` | Small utilities that verify the filter rules before release. |

## Install

Open the browser extensions page, enable developer mode, choose **Load unpacked** and select `haki-shield/` or `haki-oled-switcher/`. No build step is needed.
